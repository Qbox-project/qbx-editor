# FiveM workspace feature decisions

This is a working decision list, not an approved implementation backlog. Propose
each feature's concrete scope, ask for a yes/no decision, implement and verify
approved work, then proceed to the next decision. Keep Lua as the primary language.

| # | Feature | Decision/status |
|---|---|---|

| 3 | Searchable native/reference editor tab using the same data as hovers | Implemented; 77 Rust tests, full VS Code suite including 16 browser tests, and rendered UI checks passed. On-demand tab reuses bundled data; roughly 76 KiB additional production JavaScript |

Full VS Code suite including 18 snippet tests and rendered UI checks passed; about 50 KiB added production JavaScript |
| 5 | Resource creation wizard with maintained Lua/framework/content templates | Implemented; plain Lua/ox_lib/Qbox starters, exact read-only preview, Command Palette/Explorer entry, exclusive creation and guarded rollback. Full VS Code suite including 16 wizard tests passed; roughly 15 KiB separate bundle loaded on demand |
| 6 | Framework adapters using local source first, versioned definitions and small corrections | Implemented; QB-Core/ESX callback completion, definitions, hovers and typed payload hints from local handlers, with family/provenance/side guards and conflict handling. | 9 | Build-aware restart-on-save and additional connection/profile conveniences | Declined; keep existing manual resource actions and connection setup |

About 16 KiB webview and 35 KiB host production JavaScript, loaded on demand; no new dependency |

| 21 | Texture viewer: click-to-open YTD and DDS | Implemented and approved; single-file viewer with a searchable texture list, mip, channel and scale choices and copy actions for dictionary and texture names. About 24 KiB webview (including the BCn decoder) and 27 KiB host production JavaScript, loaded on demand; no new dependency |
| 22 | Resource control from the editor: act on the resource being edited, shortcut, Ensure and server refresh | Implemented at user request after the extension audit; `Ctrl+Alt+R` restarts the resource of the active file, the FiveM menu is on editors, tabs and manifests, replies end the wait after a short silence instead of a fixed three seconds, and an unknown resource offers `refresh`. | 27 | Texture export: save the previewed mip as PNG from the asset browser | Implemented at user request; the browser encodes the canvas it shows and the host writes the file the user places |
| 28 | Editor integration: tool list on the status bar, Restricted Mode, terminal trace links, restored tabs, MCP configuration copy, remembered log file | Implemented at user request after the extension audit; see CHANGELOG.md |
| 29 | Texture editing: replace, add, rename and delete YTD textures from PNG files | Implemented at user request; the texture viewer became an editor with undo, save, revert and backup. PNG decoding, power-of-two resizing, mip generation in linear light, BC1/BC3/BC4/BC5/BC7 and uncompressed encoding and the Legacy and Gen9 dictionary writer are written for the extension, with no new dependency. Checked on 31 published dictionaries (1,478 textures) read back by CodeWalker in both layouts and on a Direct3D 11 driver; not loaded in the game. 10 data tests and a host test that edits, saves and undoes in a real tab. Host bundle grows from 27 to 77 KiB and the webview from 24 to 26 KiB of production JavaScript, loaded on demand |

Every proposal should state what the user will see, how data is maintained, and
its effect on extension size/startup. Prefer shared existing indexes/data and
load substantial UI or asset features only when used. Other native argument
families, general type-analysis improvements, full debugging and RedM support
need their own scope decision rather than being included implicitly.
