# Third-party components

The bundled asset preview uses **@bis-toolkit/bcn 1.0.2**, part of
[BIS-Toolkit](https://github.com/Koncord/BIS-Toolkit/tree/main/packages/bcn),
under **GPL-3.0-or-later**, the same license as this extension. The full GPL v3
license is included in [LICENSE](LICENSE). Source and the exact pinned dependency
are identified in `package.json` and `package-lock.json`; the decoder is bundled
only in the asset preview browser script.

The 3D model viewer bundles the same decoder for its texture previews, and the
texture editor bundles it to export textures as PNG files.

The map viewer's dictionary of Meta structure, field and enum names lists
identifiers of the game's data schemas. Each entry was checked against the
hashes recorded in [CodeWalker](https://github.com/dexyfex/CodeWalker)
(`MetaNames.cs`, commit `485d56bec00262ed7fa472261cce7bbc6202b96e`),
Copyright (c) 2017-2019 dexyfex. CodeWalker publishes no license for that file.
No CodeWalker source code is included; the map, model and collision readers are
written for this extension.

The reference catalogs in `data/reference-catalogs.json` list the IDs and names
of blip sprites and colours, marker types, and ped, vehicle and weapon models.
They are generated by `scripts/update-reference-catalogs.mjs` from the game
reference pages of [citizenfx/fivem-docs](https://github.com/citizenfx/fivem-docs),
at the commit the file records under `source`. Only identifiers, display names
and groups are taken; no prose or images.

The snippet and Lua utility bundles use **jsonc-parser** under the MIT license.
Its full license notice is retained in the applicable JavaScript bundles.

The reference browser uses **marked** under the MIT license. Its full license
notice is retained in the reference browser bundle.
